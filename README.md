# 🛍️ Perfume E-commerce Application

A complete, modern e-commerce mobile application for luxury perfumes built from scratch using **Flutter** and **Dart**. The project features an elegant UI/UX design, clean state management, and full integration with backend RESTful APIs.

## 🚀 Key Features
* **User Authentication:** Secure user signup, login, and profile management.
* **Product Catalog:** Advanced filtering by brand, fragrance notes, and price range.
* **Shopping Cart & Checkout:** Fully functional cart system with an optimized checkout flow.
* **State Management:** Implemented clean and efficient architecture to handle app state.
* **API Integration:** Connected seamlessly with backend services using RESTful APIs.

## 🛠️ Tech Stack
* **Frontend:** Flutter | Dart
* **State Management:** Provider / BLoC
* **Database & APIs:** RESTful APIs / JSON
